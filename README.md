### 📌 Things I've built
| Project | What it does |
|---|---|
| [**MetaMatch**](https://github.com/NamikazeAsh/MetaMatch) | Hybrid AI coach for competitive Pokémon that runs fully local. A deterministic battle engine (Smogon calc + ladder stats) does the reasoning, a small LLM explains it, and a verifier rejects contradictions. Takes a 3B model from **18% → 100%** on factual battle questions (**97.5%** on blind held-out). RAG, multi-agent routing, CI-gated benchmark. |
| [**BoxBox**](https://github.com/NamikazeAsh/BoxBox) | F1 pit strategy optimizer + race outcome predictor (FastF1, Jolpica-F1) |
